# Support

AI Manager is a community-supported open-source project. Support happens in
the open on GitHub.

## Where to ask

- Bugs: open a bug report with the issue template.
- Usage or configuration questions: open a question with the issue template.
- Documentation problems: open a documentation issue.
- Feature proposals: open a feature request.

Search open and closed issues first; many questions already have an answer.

## What to include

- the AI Manager version shown in Settings;
- operating system and architecture;
- the tool or desktop app involved;
- reproduction steps, the expected result, and the actual result.

Redact API keys, authorization headers, file contents, account identifiers, and
private logs before attaching diagnostic information. AI Manager's own logs are
redacted, but pasted terminal output and configuration files are not.

## Security

Do not report vulnerabilities in public issues. Follow
[SECURITY.md](SECURITY.md).

## Releases

Official installers are published on the
[Releases page](https://github.com/OnlistTeam/ai-manager/releases). Only builds
from that page are supported; local builds are not release artifacts.
